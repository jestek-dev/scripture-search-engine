# Expected conformance slices

One file per release identity, named `<engineVersion>-<layerFingerprint first
12 hex>.json`, generated by `conformance/scripts/generateExpected.ts` against
the exact artifact the release ships and committed in the release train.

Currently EMPTY, honestly: the first consumer-facing release this kit
applies to is the P7.6 terminus, whose artifact has not been minted yet.
Nothing here is pre-generated from a stand-in database — a slice for the
wrong identity would make every consumer run report `not-applicable`, and a
slice presented as release evidence before the release exists would be the
kind of decorative guarantee this repo's gate discipline forbids.
