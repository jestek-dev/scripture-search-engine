# Team-memory export — scripture-search-engine

These 55 files are a verbatim export (made 2026-08-27) of Claude's team
memory for this project (`/tmp/claude/memory/team/silo/`), preserved here so
the project's working record survives the deletion of the Claude project
that produced it.

- **`MEMORY.md`** is the index — one line per memory, newest first. It reads
  as a dated ledger of the whole project (2026-08-05 → 2026-08-27) and is
  the best place to start.
- Every other file is a topic memory: what happened, what was verified, what
  was decided, and what remained open at the time it was last updated. Each
  carries a YAML front-matter header with its one-line description and
  last-modified timestamp.
- `[[double-bracket]]` references between files are memory cross-links; the
  target is the same-named `.md` file in this directory.
- Files were written contemporaneously by the sessions doing the work. They
  are honest working notes, not polished documents: point-in-time claims
  (open PRs, CI state, branch tips) are snapshots that later files may
  supersede — newer entries win.
- Verified 2026-08-27: no secrets or credentials appear in any file.

`HISTORY.md` (one level up) is the narrative distillation of this ledger;
these files are the primary record behind it.
