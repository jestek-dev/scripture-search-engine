### Phase 8 — THE MEGA-SWEEP (final phase; full detail)

**Charter (Jesse's words, operationalized):** throw every conceivable search at the system — thousands to hundreds of thousands; document every wrong or incomplete finding (wrong verse, poor prioritization, missing verse); fix everything confidently wrong; route everything uncertain to Jesse for approval; theological soundness above all. **Binding sequencing (his follow-up):** the sweep runs only after every other phase is implemented and merged. Infrastructure (MS-1..MS-11) is built in parallel from Phase 1 and shaken down on interim builds; only the certified exit-bar runs (MS-14) require the terminus.

**Hard preconditions (the sweep does not start certification until all true):** (1) main green — the P0.1 signatures landed; (2) re-pins + mint landed — the sweep runs against a minted, tagged artifact, never ad-hoc reconstructions (the audit's caveat, not inherited); (3) Phases 3–7 landed — the sweep is the verification and residue-hunt over the FINISHED system plus the discovery engine for what the phases missed.

**Scale (floors ratified in J43, so no implementer renegotiates silently):** Ring 0 ≈ 10²–10³ (the maintained human-graded battery). Ring 1 = committed universe: grammar-compiled ≥ 15,000 (est. 16–22k, per-grammar arithmetic in MS-3) + frozen AI paraphrases ≥ 25,000 (from ~2,340–2,765 deterministically selected seeds × 12, with a defined two-step shortfall lever) — total ≥ 40,000 committed. Ring 2 = derived perturbation universe: 100% of Ring 1 perturbed (k=2 per grammar line, k=3 per paraphrase line) + reference variants — est. 119–152k, floor ≥ 100,000. Cost: paraphrase generation ≈ $30; AI grading ≈ $320/full pass, $1,200–$3,000 phase total; runtime ≈ 60–90 min per full CI sweep; Jesse's grading hours itemized and capped (MS-9).
